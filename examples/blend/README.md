# Frameyard blend example

A 12-second, 1920×1080, 30 fps timeline that demonstrates every supported CSS
blend mode on composition and video clips. Four video tracks build one frame:

- `v1` **backdrop** — an opaque HTML composition with a grid, concentric rings,
  and a dark vignette. It omits `width`, `height`, and `fps` and inherits the
  project format, so it is captured at the timeline's own size.
- `v2` **aurora** — a transparent HTML composition with three blurred color
  blobs. Its clip uses `blend: "screen"` for the full 12 seconds.
- `v3` **ink** — a local 1280×720 H.264 clip scaled to fill the project frame.
  Twelve touching clips play one second each, cycling through all 12 supported
  modes in timeline order.
- `v4` **labels** — a transparent HTML composition in normal mode. It lists the
  modes and their time ranges, and draws a progress bar from the `--fy-progress`
  frame-state variable.

The mode sequence on `v3` is:

| Time | Mode |
| --- | --- |
| 0–1 s | `normal` |
| 1–2 s | `multiply` |
| 2–3 s | `screen` |
| 3–4 s | `overlay` |
| 4–5 s | `darken` |
| 5–6 s | `lighten` |
| 6–7 s | `color-dodge` |
| 7–8 s | `color-burn` |
| 8–9 s | `hard-light` |
| 9–10 s | `soft-light` |
| 10–11 s | `difference` |
| 11–12 s | `exclusion` |

The aurora is transparent, so its `screen` blends only where its blobs have
alpha. The video is opaque, so its whole scaled frame participates in the blend.
The labels layer stays in `normal` mode so the copy remains readable.

Blend modes are static per clip. The example uses consecutive clips on `v3` to
show every mode in one timeline; it does not animate `blend` itself. `hue`,
`saturation`, `color`, and `luminosity` are rejected because they need
cross-channel math and are not part of the supported set.

Preview composites with Chromium `mix-blend-mode`; production uses FFmpeg's
`blend` filter plus an alpha mask. The preview stage stacks by track order and
is isolated from the preview chrome. Small scaling, alpha, and color differences
between preview and the final encode are expected.

## Files

```text
examples/blend/
  compositions/backdrop.html   opaque base composition
  compositions/aurora.html     transparent screen layer
  compositions/labels.html     transparent mode list and progress layer
  timelines/blend.timeline.json
  assets/ink.mp4               procedural 12-second source clip
  scripts/make-ink.sh          regenerate assets/ink.mp4
  video.config.js
```

The timeline lives in `timelines/blend.timeline.json`; the project format and
entries are fixed in `video.config.js`. `backdrop.html` demonstrates the
optional composition format: with `width`, `height`, and `fps` omitted it
renders at the project's 1920×1080, 30 fps, while the other compositions keep
declaring their format explicitly.

## Commands

From the repository root:

```sh
pnpm build
node dist/cli.js check blend-timeline --project examples/blend
node dist/cli.js still blend-timeline --frame 15,45,75,105,135,165,195,225,255,285,315,345 --project examples/blend --out blend-stills
node dist/cli.js still blend-timeline --frame 285 --project examples/blend --out blend-soft-light.png
node dist/cli.js render blend-timeline --project examples/blend
node dist/cli.js dev --project examples/blend
```

The batch still captures one representative frame per mode into `blend-stills/`
using the same clip capture and composite path as the render. `render` writes
`out/blend-timeline.mp4` inside the project by default; use `--out <file.mp4>`
to choose another path. `dev` lists the compositions and the timeline in the
preview.

## Source clip

`assets/ink.mp4` is a 12-second, 1280×720, 30 fps rotating gradient with a
silent AAC track, generated by FFmpeg. Regenerate it with:

```sh
bash examples/blend/scripts/make-ink.sh
```

Pass an output path as the first argument to write elsewhere. Replace
`assets/ink.mp4` with any local, seekable MP4 or WebM that is at least 12 seconds
long; remote URLs and live streams are not supported. If you use a different
length, update the clip durations and source in-points in the timeline.
